# Лабораторные работы по Django

Учебный проект блога, разработанный в рамках курса по веб-разработке на Python / Django.

Проект выполнен на основе книги «Django 4 в примерах» (Антонио Меле) и лекционных материалов.

---

## Структура веток проекта

Каждая лабораторная работа выделена в отдельную ветку Git:

* **`lab1`** — Базовое приложение блога:
  - Модель `Post` с менеджером опубликованных записей `PublishedManager`.
  - Панель администратора `PostAdmin` с фильтрами, поиском и предзаполнением слага.
  - Представления списка постов (`post_list`) и детальной страницы (`post_detail`).
  - Базовый шаблон с наследованием и стилями.

* **`lab2`** — Продвинутый функционал:
  - Канонические SEO-URL с датой (`unique_for_date`).
  - Постраничная разбивка (пагинация) через `Paginator`.
  - Классовое представление `PostListView`.
  - Форма отправки статьи по email (`EmailPostForm`) с консольным бэкендом.
  - Система комментариев к статьям (модель `Comment`, форма `CommentForm`, модерация).

* **`lab3`** — Расширение приложения блога:
  - Тегирование постов с помощью библиотеки `django-taggit`.
  - Рекомендация похожих постов по общим тегам через агрегацию `Count('tags')`.
  - Кастомные шаблонные теги (`total_posts`, `show_latest_posts`, `get_most_commented_posts`) и фильтр `markdown`.
  - Карта сайта `sitemap.xml` на базе `django.contrib.sitemaps`.
  - Новостная RSS-лента `feed/` через `django.contrib.syndication`.
  - Полнотекстовый поиск по триграммному сходству на базе PostgreSQL (`pg_trgm`).

## Установка и запуск

1. Клонировать репозиторий и перейти в папку проекта:
```bash
git clone https://github.com/Korgan05/depython.git
cd depython
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Выполнить миграции и запустить сервер разработки:
```bash
cd mysite
python manage.py migrate
python manage.py runserver
```

4. Открыть в браузере:
- Блог: `http://127.0.0.1:8000/blog/`
- Поиск: `http://127.0.0.1:8000/blog/search/`
- RSS-лента: `http://127.0.0.1:8000/blog/feed/`
- Карта сайта: `http://127.0.0.1:8000/sitemap.xml`
- Панель управления: `http://127.0.0.1:8000/admin/`
